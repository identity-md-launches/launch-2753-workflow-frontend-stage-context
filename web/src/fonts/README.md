# Bundled Google Fonts

DM Sans and Pixelify Sans, normal weights 400, 600 and 700, downloaded from the official Google Fonts CSS service. Source CSS: https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;600;700&family=Pixelify+Sans:wght@400;600;700&display=swap . Font binaries come from fonts.gstatic.com and are bundled locally for reliable static hosting. CSS lives in ../fonts.css. Safe fallbacks are Arial/sans-serif and Courier New/monospace.

SIL Open Font License texts are in web/public/licenses/ and included in the static export. No third-party font provider is contacted at runtime.
